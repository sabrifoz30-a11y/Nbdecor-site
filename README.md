# nbdecor-site

متجر ورد اصطناعي بالجملة (الجزائر).

- المنتجات مرتبة حسب السعر، وكل منتج فيه صور عدة يتنقّل بينها الزبون.
- الزبون يختار اللون أو رقم الموديل والكمية، ثم يضيف المنتج إلى السلة.
- تُرسل الطلبية جاهزة عبر واتساب، والدفع عند الاستلام.
- لوحة التاجر: رفع الصور، وقراءة المرجع والسعر وعدد الورد بالذكاء الاصطناعي.

## كيف يعمل
- `index.html`: صفحة المتجر للزبائن، وتعمل وحدها على GitHub Pages.
- `images/`: صور المنتجات.
- الإدارة (إضافة المنتجات وقراءة الأسعار بالذكاء الاصطناعي) تتم في claude.ai، ثم تُنقل المنتجات والصور إلى هنا.
